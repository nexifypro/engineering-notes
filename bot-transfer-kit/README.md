# Build-Operate-Transfer: transfer kit

Templates for the article **Build-Operate-Transfer fails in the Transfer** on the
[NexifyPro blog](https://nexifypro.com/blog/build-operate-transfer-fails-in-the-transfer).

| File | What it is for |
|---|---|
| `readiness-scorecard.md` | The ownership-readiness gates, with thresholds, to agree at signing and score monthly |
| `readiness-scorecard.csv` | The same gates as a sheet you can import |
| `platform-ownership-matrix.md` | Every account, key and subscription that must change hands, with an owner column |
| `transfer-plan-90-days.md` | Week-by-week transfer plan with checkpoints |
| `raci.md` | Who is responsible, accountable, consulted and informed across Build, Operate and Transfer |
| `questions-for-your-bot-vendor.md` | What to ask any BOT vendor before signing, including us |

Copy them into your engagement repository and edit in place. Everything is MIT licensed.
