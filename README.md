# NexifyPro engineering notes

Runnable code, configs and templates behind the articles on the
[NexifyPro blog](https://nexifypro.com/blog). One folder per article. Each folder has its own
README with setup steps, tests, and the date and tool versions it was last verified with.
Every folder has a GitHub Actions workflow that runs its tests or validation on each change.
